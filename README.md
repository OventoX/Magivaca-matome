# マジカルバケーション 攻略サポート (Magivaca-matome)

GBA『マジカルバケーション』（2001年、任天堂／ブラウニー・ブラウン）の総合攻略支援Webツールです。  
ゲームプレイ中に手元で精霊の居場所・要求アイテムを素早く検索・確認できるチェックリストに加え、レベリング適地・シナリオ攻略チャート・お風呂セット入手チャート・システム解説・金貨銀貨稼ぎの法則を収録した静的Webアプリケーションです。

- **公開URL (GitHub Pages)**: [https://oventox.github.io/Magivaca-matome/](https://oventox.github.io/Magivaca-matome/)
- **リポジトリ**: [https://github.com/OventoX/Magivaca-matome](https://github.com/OventoX/Magivaca-matome)

---

## 🌟 主な機能とタブ構成

白〜淡いグレー基調の落ち着いたドキュメント志向デザインを採用。スマートフォン・PCの双方で快適に閲覧・チェック操作が可能です。

### 1. 🧚 精霊データベース＆チェックリスト（全112体）
- **属性別フィルター**: 火・風・毒・美・刃・音・石・虫・木・獣・水・雷・古・闇・光・愛（全16属性）
- **プレーン別フィルター**: 光のプレーン / 闇のプレーン / 死のプレーン
- **要求種別フィルター**: 金貨・銀貨 / グミ関連 / まつぼっくり / しっぽ / 戦闘 / 特殊条件 / なし
- **リアルタイム検索**: 居場所名、要求アイテム、条件、備考によるインクリメンタル検索
- **取り返しのつかない要素の警告表示**:
  - ずんどこ穴のトースト（ドワーフ説得で消滅）
  - 愛の精霊（スノウヘア直後限定、バダブーン、クライン未破壊、カエルグミ捕獲数制限）
  - 光の精霊（闇精霊ニルヴァの仲間数制限）
  - シサバレイ10の闇精霊加入前の光転向禁止
- **進捗トラッカー**: 仲間にした精霊をワンタップでチェック。属性別（○/7）および全体（○/112）の進捗を自動計算。
- **端末内完全保存**: 進捗はブラウザの `localStorage` にのみ保存（外部通信一切なし・完全オフライン対応）。バックアップ（JSONエクスポート／インポート）機能付き。

### 2. ⚠️ 精霊コンプリート手順＆警告
- Wikiの「精霊コンプリート」節に基づく**正しい攻略順序（愛 ➔ 光 ➔ 闇）**と必須ルールの解説
- チェックリストの進捗と連動した**動的警告表示**（例: 闇精霊を仲間にしている状態で光精霊が未コンプの場合にアラート表示）

### 3. 📈 レベリング（経験値稼ぎ）ガイド
- **経験値の分配法則**: 戦闘終了時の獲得経験値はパーティ全員（戦闘不能者・人形含む）で均等分割（頭数割り勘）される仕様を解説。
- **レベル上限・経験値推移**: LV1〜LV999の推移。LV88以降はレベルアップごとの必要経験値が99,999で一定となる仕様表。
- **魔法経験値・連打稼ぎ**: 魔法レベル（LV1〜100）と魔法経験値の仕様。風『マッハライン』、石『カテナ』、美『ホワイトローズ』、愛『天使のチャージ』連打などの高速稼ぎテクニック。
- **進行度・レベル帯別おすすめ狩り場（全7箇所）**:
  - 序盤（LV1〜15）：森の洞窟〜ベナコンチャ遺跡周辺（宿屋往復の安全地帯）
  - 序盤〜中盤（LV15〜25）：ラ・ロッシュの塔
  - 中盤（LV25〜40）：リギニオ密林〜クムヤムト砂漠
  - 中盤〜終盤（LV40〜55）：キスニカ鉱山〜アクアビット城
  - 終盤（LV55〜75）：荒廃の地〜死の回廊〜モギナス魔窟（道中）
  - クリア後・最高効率（LV80〜200+）：ガラムマサラ（5の倍数階ボス即時復活往復 ★Wiki推奨）
  - エンドコンテンツ（LV190〜200+）：シサバレイ／リドナヒー（アミーゴ100人裏ダンジョン）

### 4. 🗺️ シナリオチャート攻略
- 全5プレーン（物質のプレーン、光のプレーン、闇のプレーン、死のプレーン、ガラムマサラ）の攻略要点。
- 各プレーンの「到達条件」「重要イベント」「仲間加入」「ボス攻略」「取り返しのつかない要素」を網羅。

### 5. ♨️ お風呂セット入手チャート（第4弾 NEW）
- **おふろ装備一式の性能**:
  - せんめんき（頭）、ゆかた（体）、ゲタ（足）、おふろセット（装飾品）の4部位。
  - 一式装備時の驚異的セット効果：**力+51 / 守+51 / 速+51 / 精+51 / MP+51%**（全能力+50底上げ）。
- **入手手段**: 魔バスの「やさがし」乱数調整（通信要素不要・完全オフライン可能）。
- **ステップ別手順チャート**:
  - **ルート1（増殖ループ）**: 闇のプレーンで起点を掴み、光でゲタ・お風呂セット、闇でゆかたを回収する無限増殖ループ。
  - **ルート2（一式コンプ特化）**: せんめんき・てぬぐいを含め最短手順で一式を揃えるルート。
- **注意点・警告**: 愛の精霊コンプリート後の実施推奨、アイテム枠満杯厳禁、ワープ以外の移動・戦闘禁止。

### 6. ⚙️ システム解説
- **仲間システム**: クラスメイト全16名の成長タイプ・特殊能力（アランシアのハズレ宝箱コイン、ペシュのミミズグミ穴コイン、カベルネのカエル捕獲回避等）。
- **魔法システム**: 16属性のすくみ・反発・コンボ仕様。
- **成績システム**: クリア時の行動集計と称号評価。
- **アミーゴシステム**: 通信人数特典とアミーゴ100人（裏ダンジョン進入）の重要性。
- **その他**: こんにゃくいも、やさぐれドワーフなどの仕様解説。

### 7. 🐟 稼ぎ・寿命ガイド
- **ピラニアの金貨銀貨法則表**: 累計入金額の「余り」と入手できるコインの対応表、入金額による余りのシフト法則表、効率的な2,000ブラー連打法。
- **ミミズグミ・カエルグミ・まつぼっくりの寿命仕様**: 各種グミやまつぼっくりの「寿命」の仕組みと注意事項。

## 📜 データの出典方針

- **一次情報出典**: [マジカルバケーション攻略Wiki](https://wikiwiki.jp/magivaca/)
- **データ捏造禁止の徹底**: Wikiに書かれていない数値・場所・条件は作成せず、推測で埋めていません。
- **算出データの明記**: おすすめレベリング場所など、モンスター図鑑や出現レベルデータから機械的に導出した項目は「【データ算出】」と明記しています。
- **著作権への配慮**: Wiki本文の長文をそのまま転載せず、事実情報（場所・要求・条件・数値等）を構造化し、要点の記述にとどめています。
- **出典リンク**: 各エントリに出典URLを持たせ、画面上から一次情報を確認できるようにしています。

## 🛠 技術スタック・ローカル実行方法

- **構成**: HTML5 / CSS3 / Vanilla JavaScript（ビルド不要、トランスパイル不要）
- **外部依存**: **完全ゼロ**（外部CDNやフレームワークは一切使っていません）
- **プライバシー**: ユーザーのチェックデータはブラウザ内の `localStorage` にのみ保存され、外部サーバへ送信されることはありません。
- **ローカル実行**:
  リポジトリをクローンまたはダウンロードし、`index.html` をブラウザで直接ダブルクリックして開くだけで即座に動作します（Webサーバー不要）。
