# マジカルバケーション 攻略サポート (Magivaca-matome)

GBA『マジカルバケーション』（2001年、任天堂／ブラウニー・ブラウン）の精霊データベース＆コンプリート支援チェックリストです。  
ゲームプレイ中に手元で精霊の居場所・要求アイテムを素早く検索・確認でき、仲間にした精霊をブラウザ内に記録（チェック）できる静的Webアプリケーションです。

- **公開URL (GitHub Pages)**: [https://oventox.github.io/Magivaca-matome/](https://oventox.github.io/Magivaca-matome/)
- **リポジトリ**: [https://github.com/OventoX/Magivaca-matome](https://github.com/OventoX/Magivaca-matome)

---

## 🌟 主な機能

### 1. 精霊データベース（全16属性 × 各7体 ＝ 実測 112体収録）
- **属性別フィルター**: 火・風・毒・美・刃・音・石・虫・木・獣・水・雷・古・闇・光・愛（全16属性）
- **プレーン別フィルター**: 光のプレーン / 闇のプレーン / 死のプレーン
- **要求種別フィルター**: 金貨・銀貨 / グミ関連 / まつぼっくり / しっぽ / 戦闘 / 特殊条件 / なし
- **リアルタイム検索**: 居場所名、要求アイテム、条件、備考によるインクリメンタル検索
- **取り返しのつかない要素の警告表示**:
  - ずんどこ穴のトースト（ドワーフ説得で消滅）
  - 愛の精霊（スノウヘア直後限定、バダブーン、クライン未破壊、カエルグミ捕獲数制限）
  - 光の精霊（闇精霊ニルヴァの仲間数制限）
  - シサバレイ10の闇精霊加入前の光転向禁止
- **一次情報出典リンク**: 全112体各エントリに出典（Wikiの属性アンカー付きURL）を掲載

### 2. コンプリート・チェックリスト
- 仲間にした精霊をワンタップでチェック
- 全体進捗バー（`○ / 112 (○%)`）を上部に常時表示
- 16属性ミニトラッカー（各属性 `○ / 7` 進捗、コンプリートで緑色にハイライト）
- チェック進捗はブラウザの `localStorage` に自動保存（外部通信一切なし・完全オフライン対応）
- 進捗データのバックアップ（JSONエクスポート／インポート）機能
- 一括リセット機能

### 3. コンプリート攻略手順＆警告パネル
- Wikiの「精霊コンプリート」節に基づく**正しい攻略順序（愛 ➔ 光 ➔ 闇）**と必須ルールの解説
- チェックリストの進捗と連動した**動的警告表示**（例: 闇精霊を仲間にしている状態で光精霊が未コンプの場合にアラート表示）

### 4. 稼ぎ・寿命ガイドパネル
- **ピラニアの金貨銀貨法則表**:
  - 累計入金額の「余り」と入手できるコインの対応表
  - 入金額による余りのシフト法則表
  - 効率的なコイン収集法（2,000ブラー連打法）
- **ミミズグミ・カエルグミ・まつぼっくりの寿命仕様**:
  - 各種グミやまつぼっくりの「寿命」の仕組みと注意事項

## 📜 データの出典方針

- **一次情報出典**: [マジカルバケーション攻略Wiki](https://wikiwiki.jp/magivaca/)
  - [精霊ページ](https://wikiwiki.jp/magivaca/%E7%B2%BE%E9%9C%8A)
- **データ捏造禁止の徹底**: Wikiに書かれていない数値・場所・条件は作成せず、推測で埋めていません。
- **著作権への配慮**: Wiki本文の長文をそのまま転載せず、事実情報（場所・要求・条件・数値等）を構造化し、要点の記述にとどめています。
- **出典リンク**: 各エントリに出典URLを持たせ、画面上から一次情報を確認できるようにしています。

## 🛠 技術スタック・ローカル実行方法

- **構成**: HTML5 / CSS3 / Vanilla JavaScript（ビルド不要、トランスパイル不要）
- **外部依存**: **完全ゼロ**（外部CDNやフレームワークは一切使っていません）
- **プライバシー**: ユーザーのチェックデータはブラウザ内の `localStorage` にのみ保存され、外部サーバへ送信されることはありません。
- **ローカル実行**:
  リポジトリをクローンまたはダウンロードし、`index.html` をブラウザで直接ダブルクリックして開くだけで即座に動作します（Webサーバー不要）。

## 🚀 GitHub Pages 公開設定

1. リポジトリの **Settings** > **Pages** を開きます。
2. **Build and deployment** の **Source** で `Deploy from a branch` を選択します。
3. **Branch** で `main` を選び、フォルダを `/ (root)` に設定して **Save** をクリックします。
4. 数分で [https://oventox.github.io/Magivaca-matome/](https://oventox.github.io/Magivaca-matome/) にて公開されます。
