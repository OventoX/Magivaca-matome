## 2. 精霊データの想定件数と、表記ゆれ・例外の一覧

- **精霊総数**: **実測 112 体**（16属性 × 各7体）
- **属性（全16属性）**: 火・風・毒・美・刃・音・石・虫・木・獣・水・雷・古・闇・光・愛

### 表の列構成と表記ゆれ・例外
Wikiの「精霊」ページのテーブルは、属性によって列数と意味が以下のように異なります。

1. **基本形式（4列：11属性）**
   - 列構成：`['居場所', '場所詳細', '要求', '条件・備考']`
   - 対象属性：火、風、毒、刃、音、石、虫、獣、水、雷、古
   - **例外・注記**:
     - **石（フリント）**: 「条件・備考」列に「ミミズグミ捕獲数○以上」の出現条件が同居。
     - **虫（バズ）**: 「条件・備考」列に「虫メガネ」所持が必須条件として同居。
     - **音（ハミング）**: 要求列に「ハモニック金貨2（1）」の表記ゆれ（カッコ内は音属性主人公時の必要枚数）。
     - **火（トースト #3）**: 居場所詳細に「※ドワーフを一人でも説得するといなくなります」の消滅警告が記載。
2. **美（パウダー：5列）**
   - 列構成：`['居場所', '場所詳細', '要求1', '要求2', '条件・備考']`
   - **例外**: 「要求1」にミミズグミ所持数制限（80以下/60以下/40以下/20以下/0）、「要求2」にガニック金貨枚数が入る2重要求。
3. **木（スティック：5列）**
   - 列構成：`['居場所', '場所詳細', '出現条件(まつぼっくり獲得数)', '要求(まつぼっくり譲渡数)', '備考']`
   - **例外**: まつぼっくりの「累計獲得数（出現条件）」と「譲渡数（消費要求）」が別列に分離。
4. **闇（ニルヴァ：5列）**
   - 列構成：`['居場所', '場所詳細', '出現条件(カエルグミ捕獲数)', '要求', '備考']`
   - **例外**: 要求がすべて「戦闘に勝利」（テーブル上では2体目以降「〃」と省略表記。データ化時に「戦闘に勝利」に展開）。
5. **光（ルクス：5列）**
   - 列構成：`['居場所', '場所詳細', '出現条件', '要求', '備考']`
   - **例外**: 出現条件が「時間経過（41秒後）」または「なし」。要求が「ニルヴァ○体以下」（闇精霊を仲間にしていないこと）。
6. **愛（ウィッシュ：5列）**
   - 列構成：`['居場所', '場所詳細', '出現条件', '要求(カエルグミ捕獲数)', '備考']`
   - **例外**: 出現条件が個別イベント（スノウヘア直後、ピップルス会話、バダブーン、クライン未破壊等）。要求がカエルグミ捕獲数上限（0個〜少数）。

## 3. コンプリート攻略の必須手順と取り返しのつかない要素

1. **愛 ➔ 光 ➔ 闇 の順で集める（鉄則）**
   - 愛の精霊はカエルグミ捕獲数制限（0個〜少数）があり、光の精霊は闇精霊（ニルヴァ）加入数制限（1体以下〜6体以下）があるため、闇を先に集めると光と愛が詰みます。
2. **カエルグミは愛コンプまで捕獲・購入禁止**
   - アクアビット城4とピラミッド9のウィッシュは『捕獲数0個（ピラミッドは未購入も）』が条件です。1匹でも拾う・買うとコンプ不可能になります。
3. **ずんどこ穴の火の精霊（トースト3）は最優先で仲間にする**
   - ドワーフを一人でも説得すると消滅し、二度と仲良くなれません。説得前に必ずミーロリ銀貨4枚を渡して仲間にすること。
4. **シサバレイ10の闇精霊（ニルヴァ7）まで光の魔法使いにならない**
   - シサバレイは闇の魔法使いでなければ侵入できません。光の魔法使いになると二度と入れなくなるため、必ずシサバレイ10のニルヴァを仲間にした後に光へ転向すること。アミーゴ100人が必要。
5. **タンドーリでクラインを割らない**
   - 死のプレーンのタンドーリでクラインを割ってしまうと、ガスパチョ村の愛の精霊（ウィッシュ6）が出現しなくなります。
6. **スノウヘア撃破直後にトルーナ村へ向かう**
   - ベナコンチャ遺跡の愛の精霊（ウィッシュ1）は、ボス「スノウヘア」撃破直後の移動時のみ出現します。
